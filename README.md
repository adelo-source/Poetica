# [Poetica]
## Om sidan
Vad handlar sidan om, och vem är den till för? Två–tre meningar. Sidan är en kreativ mötesplats för poesi där användare kan dela med sig av egna dikter helt anonymt eller inspireras av andras verk. 
## Skiss
Länk eller hänvisning till skissfilen i repot. Min skiss skapades i Canva och finns i filen Poetica.png som ligger i samma mapp som denna fil. 
Skiljer sig den färdiga sidan från skissen? Vad ändrades och varför? Det färdiga resultatet skiljer sig något från den ursprungliga skissen. Bland annat ser diktsektionen annorlunda ut. Utseendet skiljer sig ju mest men det är för att den första endast är en skiss av ungefär hur slutresultaet ska se ut. Jag tycker att det är bättre att inte vara för specifik när det gäller skissen för att inte begränsa sig själv så mycket. Men funktionerna är samma. 
## Funktionalitet
Vad kan besökaren göra på sidan? Vilken fil och vilka funktioner sköter det? På sidan kan besökaren publicera egna dikter anonymt via ett formulär.
Alla dessa funktioner hanteras dynamiskt via filen script.js med hjälp av DOM-manipulation och händelsehantering, i samspel med style.css.
